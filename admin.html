Rutas

Da de alta cada ruta con su número (el mismo de tu sistema) y su IBP. Al importar clientes, la columna rutaId lleva ese número.

Alta manual de cliente

Agrega un cliente a una ruta y define sus días de visita.

Clientes cargados

Un clic en cualquier campo lo guarda al toque.

Importar clientes (CSV)

Columnas esperadas: id,nombre,direccion,rutaId,frecuencia,dias,lat,lng,formato,tier (id es el número de tienda que usa el archivo de ventas; formato es SF o LF; tier es 1, 2 o 3). El formato y el tier también se pueden cargar aparte en "Datos de venta". Para bisemanal, la columna dias acepta dos días separados por "|" (ej. lunes|jueves). Si faltan lat/lng, el cliente queda marcado como "geocodificación pendiente" (hoy no hay API key de Google Geocoding conectada).

Cargar % de frescura por cliente

Se carga el % ya calculado (no ventas/devoluciones en crudo). El promedio por ruta/IBP se calcula simple sobre estos valores.

Cargar datos (4 archivos separados)

Cada archivo llega por su lado y la app los cruza por número de tienda (el mismo id de la pestaña Clientes) y por SKU. Acepta Excel (.xlsx) o CSV, con la primera fila como encabezados.

1. Ventas semanales

Columnas: tienda, sku, semana, unidades (semana 1–53). Reemplaza las ventas anteriores.

2. Formato de tienda (SF / LF)

Columnas: tienda, formato — acepta SF, LF, Small Format, Large Format.

3. Tier de tienda (1 / 2 / 3)

Columnas: tienda, tier — acepta 1, 2, 3 o "Tier 1"…

Última visita por tienda (opcional)

Columnas: tienda, ultimaVisita — fecha como 2026-10-24 o 10/24/2026. Sirve para arrancar con el historial real; después la app usa las visitas que marca el IBP.

4. Productos activos (A / B / C / Innovación)

Columnas: sku, nombre, clase, crecimiento — clase A, B, C o Innovación; crecimiento como 9.9 o 0.099. Reemplaza la lista actual.

Productos y % de crecimiento

Ajusta el % de cualquier producto; se guarda al salir del campo.

Qué clases aplican a cada formato

Un producto aparece en el pedido de una tienda solo si su clase está marcada para el formato de esa tienda.

Innovación: cuánto colocar

Cuando una tienda no tiene un producto de innovación, se sugiere lo que venden las tiendas del mismo formato y tier que ya lo tienen. Si ninguna lo vende todavía (lanzamiento), se usa esta tabla.

Vista previa. Así ve cada IBP sus metas, faltantes y sugerencias. Mirarlas aquí no las marca como leídas ni las quita: al IBP le siguen apareciendo en su momento.

Tiendas sin visita
