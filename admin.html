Clientes cargados

Importar clientes (CSV)

Columnas esperadas: id,nombre,direccion,rutaId,frecuencia,dias,lat,lng,formato (id es el número de tienda que usa el archivo de ventas; formato es SF o LF). Para bisemanal, la columna dias acepta dos días separados por "|" (ej. lunes|jueves). Si faltan lat/lng, el cliente queda marcado como "geocodificación pendiente" (hoy no hay API key de Google Geocoding conectada).

Cargar % de frescura por cliente

Se carga el % ya calculado (no ventas/devoluciones en crudo). El promedio por ruta/IBP se calcula simple sobre estos valores.

Ventas semanales del año base

CSV con una fila por tienda, producto y semana: clienteId,sku,semana,unidades (semana 1–53). Reemplaza las ventas cargadas antes. El IBP verá cuánto pedir para superar esa misma semana el año siguiente.

Productos activos

CSV: sku,nombre,clase,crecimiento — clase A, B o C; crecimiento como 9.9 o 0.099. Reemplaza la lista actual. El % se puede ajustar abajo producto por producto.

Qué clases aplican a cada formato

Un producto aparece en el pedido de una tienda solo si su clase está marcada para el formato de esa tienda. El formato de cada tienda se cambia en la pestaña Clientes.
